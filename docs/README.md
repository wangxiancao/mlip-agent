# docs/ — Agent 入门教程

给新接入本项目的 agent 的阅读与上手指引。

## 阅读顺序

1. `docs/getting-started.md` — 十分钟上手（本文档集的入口）
2. `../AGENTS.md` — 长期遵守的规则
3. `../PROJECT.md` — 项目目标、范围、完成标准
4. `../PLAN.md` — 唯一权威实施计划（动手前读对应章节）
5. `../resource/decisions.md` — 架构决策记录（ADR 全量）
6. `../STATUS.md` — 当前状态与下一步（工作台账，不入库）
