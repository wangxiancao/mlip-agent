# 决策阶梯（decision ladder）— MLIP 反应能垒计算故障诊断规则

当计算偏离预期时，按优先级从 A 到 I 逐条排查：先排除执行层与输入层问题，
再处理收敛与物理合理性问题。每条规则给出「从哪里找原因」和「怎么修」。
同一诊断下重复失败说明上次的修复是错的，不要原样重交同一输入。

## Rule A 执行层失败（exit≠0 / 超时 / 缺 input.out）

先读作业目录的 stderr.log 和 .out 末尾的 ERROR 行。区分两类：
- 基础设施：超时 → 调大 timeout_s 重交（输入不变）；缺输出文件 → 确认作业目录与路径。
- 输入错误：ERROR 行指出的语法/参数问题 → 修正 inp 后重交。

## Rule B 输入校验拒绝（write_maple_inp 返回错误）

按错误提示逐条修 JobSpec，不要换写法盲目重试：
- freq 任务的 structure 必须用 xyz_file（内联坐标会被拒绝）；
- scan 原子序号为 1-based；
- 模型-体系匹配：元素覆盖与电荷/多重度支持（如 maceoff23s 不支持电荷，ANI-2x 无 Cl）。

## Rule C opt 不收敛

- 检查起始几何：键长量级是否合理（0.9–2 Å），原子是否重叠；
- 检查 charge/multiplicity 是否配错——自由基 mult=2、O(3P) mult=3 是最常见漏配；
- 增大 opt.max_iter（如 256→512）；仍不收敛可先用更松 level 粗优化再精优化。

## Rule D 极小点 freq 有虚频（n_imag > 0）

几何未真正收敛：提高 opt 收敛等级（level=tight）重新优化，再重算 freq。
不得在带虚频的极小点上直接报告能量/能垒。

## Rule E scan 曲线异常（点数不符 / 无上升段 / 能量跳变）

- 刚性扫描从**初始几何**出发：先把被扫描键长直接改为起始值（只动相关原子）再提交；
- 点数换算：用户要 N 个点 → n_steps = N−1，delta = (终值−始值)/(N−1)；
- 确认扫描的键与反应坐标一致（断键/成键的那根），原子序号基于当前坐标顺序。

## Rule F TS 搜索失败或 TS freq 虚频数 ≠ 1

- 初猜必须接近鞍点：用给定的 ts_guess.xyz，或扫描能量最高点附近的结构；
- prfo 不收敛 → 换更近的初猜重试，不要原样重交；
- 虚频 > 1 → 收敛到了高阶鞍点：沿最大虚频的振动方向位移后重新搜索；
- 虚频 = 0 → 收敛到了极小点而非 TS：初猜离反应物/产物太近，取更接近 scan 顶点的结构。

## Rule G 能量 / 能垒数量级或符号异常

- 单位制：MAPLE 输出 Hartree，1 Hartree = 627.5095 kcal/mol = 27.2114 eV；
- 能垒公式：正向能垒 = E(TS) − E(反应物)，反向 = E(TS) − E(产物)，方向勿颠倒；
- 多物种侧的能量求和：每个物种用各自优化后的能量相加；
- charge/multiplicity 逐物种核对（阴离子 S_N2 全程 charge=−1）。

## Rule H 与参考值系统偏差但物理合理

MLIP 训练的理论级别与参考数据（高级别 WFT）不同，能垒存在数 kcal/mol 级
系统偏差是预期的：如实记录数值，不要为逼近参考值而人为「修正」参数。

## Rule I 成功确认

全部满足才算完成：各段作业收敛；虚频数符合驻点类型（极小 0 个 / TS 恰 1 个）；
能垒与反应能的符号方向合理；数量级与同类反应一致。
